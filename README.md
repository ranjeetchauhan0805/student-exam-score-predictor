# 🎓 Student Exam Score Predictor

A Machine Learning project that predicts a student's exam score using Linear Regression.

## Features

- Data Cleaning
- Exploratory Data Analysis (EDA)
- Linear Regression Model
- Model Evaluation
- Streamlit Web App

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-learn
- Joblib
- Streamlit

## Run Locally

Install dependencies:

```bash
pip install -r requirements.txt
```

Run the Streamlit app:

```bash
streamlit run app.py
```

## Model Performance

- MAE: 2.31
- RMSE: 2.79
- R² Score: 0.85"# student-exam-score-predictor"
